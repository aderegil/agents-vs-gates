# S-5 · Report revenue in one reporting currency

Epic: EPIC-RQ6 · Multi-currency checkout
Repo: analytics-ingest
Team: Data
Depends on: S-2
Risk: low

As Data, we want order amounts converted to USD for reporting, so that revenue from different currencies can be added
up.

Acceptance criteria:
- A conversion helper turns an amount in minor units of any supported currency into USD cents, using integer FX rates
  (parts per million); no floating-point amount is stored.
- It respects each currency's minor-unit digits (JPY has none).
- A currency without a rate is an error, not a zero.
