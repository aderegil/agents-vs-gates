# S-4 · Invoice only in currencies Finance can settle

Epic: EPIC-RQ6 · Multi-currency checkout
Repo: billing-service
Team: Finance
Depends on: S-2
Risk: medium

As Finance, we want billing to know which currencies we can settle and how many decimals each one has, so that an
invoice is never issued in a currency we cannot collect.

Acceptance criteria:
- Billing exposes the list of settlement currencies and the minor-unit digits of each one.
- A currency outside that list raises a clear, typed error instead of defaulting to two decimals.
- Zero-decimal currencies (JPY) are covered by tests.
