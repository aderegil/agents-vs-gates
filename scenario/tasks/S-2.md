# S-2 · Record the FX quote used at checkout

Epic: EPIC-RQ6 · Multi-currency checkout
Repo: orders-service
Team: Checkout
Depends on: S-1
Risk: medium

As Finance and Data, we want each order to say which FX quote the shopper saw, so that invoices and revenue reports
convert with the same rate the shopper accepted.

Acceptance criteria:
- POST /orders accepts an optional `fxQuoteId` (string, 1-64 characters); an invalid value is a 400.
- The order stores it and `OrderPlaced` carries it when present.
- The change is additive: no existing field of `OrderPlaced` or of `GET /orders/{id}` is renamed, removed or retyped.
