## Removed
- The decision/needs engine (`decisions.ts`, `schedule.ts`, `relationships.ts`, `dialogue.ts`, `simulation.ts` with `tick()`, the needs/traits parts of `character.ts`/`types.ts`).
- The LLM director and its server (`director.ts`, `server/director-server.js`, `server/.env.example`, `scripts/dev-ai.mjs`, `AiControl.tsx`, the `/api` dev proxy): **no model calls, no API keys**.
- The Café Aurora, Startup Nimbus and Barrio Jacaranda scenarios, the scenario picker, objectives, character panel and event feed; `oxlint`; the Vite logo favicon.

## Added
- `src/engine/replay.ts` — `ReplayEngine`, replacing `tick()`: a deterministic clock over `replay.json`; applies the steps with `t_ms ≤ clock`; seek/step back rebuild from 0; compare-view sync by key moment. Unit-tested with `node --test` (`test/replay.test.ts`).
- The **AI-SDLC Office** scenario (places come from `replay.json`, written by `replay/export.py`).
- **Avatars v2** (2026-10-11): `src/engine/pixels.ts`, `identity.ts`, `human.ts`, `agent.ts`, `portrait.ts` paint 40×48 pixel busts without the DOM (humans by seed and role; AI agents by family, role emblem and seed); `motion.ts` derives the floor poses (idle, typing, talking, CI reactions) from the replay clock. Tested in `test/avatars.test.ts`.
- `src/engine/avatarStyles.ts` — the three avatar styles (human as is; AI agent with helmet, visor, accent outline, cool palette and "AI · model" badge; systems as objects: CI tower, staging bench, dispatch board). `src/avatar-lib.ts` builds it into `console/plugins/teams/web/avatar.js` for the Teams & Avatars plugin.
- Player UI: speech bubbles with real trace text, transport and keyboard controls, timeline with key-moment markers, subtitles, events panel, presentation mode, permanent watermark, compare view, WebM clip recording, run picker (`/api/replay/list`) and the `avg:hello` handshake.
- IBM Plex Sans 400/500/600 (OFL, `src/assets/fonts/OFL.txt`), copied from the Iniciativas app.

## Build
```
npm install
npm run build   # tsc -b, then vite build -> ../web/dist (base "./"), then the avatar lib -> ../../teams/web/avatar.js
npm test        # node --test test/*.test.ts
npm run preview # serves ../web/dist; open /?replay=demo/m1-xrename-v0s0-break-repair.json
```
Standalone query parameters: `replay=<url>`, `compare=<url>`, `t=<ms>` (open at a moment), `view=map`, `present=1` (presentation look without fullscreen, for screenshots). `public/demo/` holds the exported mock fixtures (`python -m replay.fixtures.make_fixtures` regenerates them).
